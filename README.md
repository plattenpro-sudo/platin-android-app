# تطبيق بلاتين للجوال (Android)

تطبيق بسيط يعرض موقع بلاتين (`https://platin-inventory.duckdns.org`) داخل تطبيق حقيقي على الجوال،
مع دعم كامل لصلاحية الكاميرا (لعمل مسح الباركود داخل التطبيق تماماً كما في المتصفح).

**لا يحتاج Android Studio على جهازك** — يُبنى ملف APK تلقائياً على سحابة GitHub بمجرد رفع المشروع.

---

## 1) أنشئ مخزناً جديداً على GitHub

بنفس الطريقة التي أنشأت بها مخزن الموقع سابقاً:
1. اذهب إلى GitHub → **New repository**
2. الاسم: `platin-android-app`
3. اجعله **Private**
4. **لا** تفعّل README أو gitignore أو license (اتركها فارغة تماماً)
5. اضغط **Create repository**

## 2) ارفع هذا المشروع إليه

نفس خطوات GitHub Desktop المعتادة:
1. فكّ ضغط هذه الحزمة
2. **File → Add local repository** → اختر المجلد المستخرَج
3. إن ظهر خيار "create a repository" اضغطه (Git ignore: None، License: None)
4. اكتب رسالة Commit مثل "النسخة الأولى" → **Commit to main**
5. **Publish repository** → اربطه بمخزن `platin-android-app` الذي أنشأته (نفس طريقة حل مشكلة "يوجد مخزن بهذا الاسم" التي واجهتها سابقاً إن ظهرت)

## 3) البناء التلقائي يبدأ فوراً

بمجرد الرفع (Push)، يبدأ **GitHub Actions** تلقائياً ببناء ملف APK (يأخذ 3-5 دقائق أول مرة). لمتابعته:
1. افتح المخزن على موقع GitHub (`github.com/plattenpro-sudo/platin-android-app`)
2. اضغط تبويب **Actions** أعلى الصفحة
3. ستجد عملية باسم "Build APK" قيد التشغيل (دائرة صفراء) ثم ✅ خضراء عند الانتهاء

## 4) نزّل ملف APK

1. اضغط على عملية البناء المكتملة (✅)
2. انزل لأسفل الصفحة لقسم **Artifacts**
3. اضغط `platin-app-debug-apk` لتنزيله كملف مضغوط، ثم فك الضغط للحصول على `app-debug.apk`

## 5) ثبّته على جوالك

1. انسخ ملف `app-debug.apk` لجوال أندرويد (واتساب لنفسك، بلوتوث، أو رابط تنزيل مباشر)
2. عند فتح الملف على الجوال، إن ظهر تحذير "تثبيت من مصدر غير معروف"، اسمح به لمرة واحدة (إعداد أمان عادي من أندرويد لأي تطبيق خارج متجر Google Play)
3. اضغط **تثبيت**

---

## تحديث التطبيق لاحقاً

أي تعديل تريده (مثلاً تغيير الرابط، الاسم، الشعار) — عدّل الملفات وارفعها بنفس طريقة GitHub Desktop المعتادة (Commit + Push)، وسيُبنى APK جديد تلقائياً كل مرة، تنزّله بنفس خطوة "4" أعلاه.

## ملاحظات مهمة

- **هذه نسخة "Debug"** — تكفي تماماً للاستخدام الداخلي في شركتك (لا تحتاج نشرها على Google Play). إن احتجت لاحقاً نشرها فعلياً على المتجر، الأمر يختلف (يحتاج حساب مطوّر مدفوع من Google وتوقيع النسخة Release) — أخبرني إن وصلت لهذه المرحلة وسأرشدك.
- التطبيق **مجرد نافذة تعرض موقعك** — أي تحديث تنشره على الموقع نفسه (عبر خطوات النشر المعتادة على السيرفر) يظهر تلقائياً داخل التطبيق فوراً، بدون الحاجة لإعادة بناء APK جديد في كل مرة. تحتاج إعادة بناء APK فقط لو غيّرت شيئاً في **التطبيق نفسه** (الاسم، الأيقونة، الرابط).
- إن غيّرت نطاق موقعك مستقبلاً، عدّل السطر `siteUrl` داخل ملف `MainActivity.kt` وارفع التحديث.
